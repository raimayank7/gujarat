How the code GSCB0KDT011 is built

GSCB is the bank part: the letters of Gujarat State Co-operative Bank. The fifth character is always the digit 0. KDT011 is the part that names this branch.

The MICR code 362809512 is the number printed along the bottom of this branch's cheques. 362 is the city, 809 is the bank and 512 is the branch.
