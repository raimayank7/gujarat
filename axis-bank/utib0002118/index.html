How the code UTIB0002118 is built

UTIB is the bank part: the letters of Axis Bank. The fifth character is always the digit 0. 002118 is the part that names this branch.

The MICR code 380211037 is the number printed along the bottom of this branch's cheques. 380 is the city, 211 is the bank and 037 is the branch.
