How the code ESFB0007038 is built

ESFB is the bank part: the letters of Equitas Small Finance Bank. The fifth character is always the digit 0. 007038 is the part that names this branch.

The MICR code 384756002 is the number printed along the bottom of this branch's cheques. 384 is the city (the same three digits that begin the PIN code 384001), 756 is the bank and 002 is the branch.
